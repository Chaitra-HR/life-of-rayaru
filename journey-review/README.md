# Chapter 07 reference frames

Captured from the current build at 1600×900. These are the intended reading of
each beat — if a change makes the chapter diverge from these, that is either the
change working or the change breaking something, and these tell you which.

Regenerate them with `tools/shot-server.js` (see [`../HANDOVER.md`](../HANDOVER.md),
section 6). Chapter-local `u` converts to scroll position as
`t = 0.570 + u × 0.085`.
